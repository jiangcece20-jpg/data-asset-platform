# PC 端找数买数模块设计

## 概述

在现有 Vue 3 原型项目中新增 PC 端找数买数模块。当前项目已有移动端 APP 找数买数（`/app/*` 路由）和 PC 运营后台（`/admin/*` 路由）。PC 找数买数作为数据资产平台 PC 门户的一个菜单/模块嵌入，与移动端 APP 形成多端协同。同时需对 App 端做少量调整（Mine 页面新增"我的账单"Tab + API 订单详情增加用量区块）。

## 架构设计

### 方案选型

采用**独立 PC 视图层**方案：新建 `src/views/portal/` 目录和 8 个 PC 专用页面组件。路由前缀 `/portal/*`。新建 `PortalShell.vue`（左侧导航 + 内容区）。

- **复用层**（零改动）：Store（catalog/cart/user/approval）、类型（domain/resource）、数据（products/resources/mocks/seed）、工具函数（productMeta/id）
- **新建层**：PortalShell 布局 + 8 个页面组件 + 路由 + App.vue 切换器扩展
- **移动端不改动**（除 Mine.vue 的账单 Tab 调整）

### 路由结构

```
/portal                    → PortalShell（左侧导航 + 内容区）
  /portal/home             → 门户首页（推荐位、快捷入口）
  /portal/search           → 统一搜索（关键词 + AI双模式，结果混排）
  /portal/product/:id     → 商品详情（两栏布局）
  /portal/checkout/:id    → 购买结算
  /portal/mine            → 我的购买（已购列表、会员）
  /portal/bills           → API用量账单
  /portal/demand          → 需求提报
```

### App.vue 改动

顶部切换器从两项变三项：`移动端原型 | PC门户 | 运营后台`

```typescript
const mode = computed(() => {
  if (route.path.startsWith('/admin')) return 'admin'
  if (route.path.startsWith('/portal')) return 'portal'
  return 'app'
})
```

`<main>` 根据 mode 渲染 `PhoneShell` / `PortalShell` / `AdminShell`。

### 文件结构

```
src/
  layouts/
    PortalShell.vue              ← 新建
  views/portal/                   ← 新建目录
    PortalHome.vue
    PortalSearch.vue
    PortalProductDetail.vue
    PortalCheckout.vue
    PortalMine.vue
    PortalBills.vue
    PortalDemand.vue
  views/mobile/
    Mine.vue                     ← 修改（新增"我的账单"Tab）
  router/index.ts                ← 新增 /portal/* 路由组
  App.vue                        ← 切换器增加 PC门户
```

## 页面设计

### 1. 统一搜索页（PortalSearch）

#### 布局

搜索框支持双模式：默认关键词模式，可切换到 AI 问答模式。结果混排展示。

```
┌─────────────────────────────────────────────────┐
│         [🔍 关键词] [🤖 AI问答]    [搜索]          │
├─────────────────────────────────────────────────┤
│  排序：默认 | 价格↓ | 最新          共 6 条结果    │
├─────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────┐    │
│  │ [看板]🏪 全国货运价格指数      ¥299/12月 │    │
│  │        覆盖全国300+城市·日更      详情 →   │    │
│  ├─────────────────────────────────────────┤    │
│  │ [🏠内部] 司机绩效周报            跳转 →   │    │
│  │         数据源:运单系统·柱状图            │    │
│  ├─────────────────────────────────────────┤    │
│  │ [API]🏪 资格核验API            会员免费   │    │
│  │        企业资质在线核验·1000次/月 详情 →   │    │
│  └─────────────────────────────────────────┘    │
└─────────────────────────────────────────────────┘
```

AI 模式下，结果区上方多一个 AI 回答摘要区块，下方同样混排结果列表。

#### 交互逻辑

- **关键词模式**：输入关键词 → `catalog.search(query)` + `catalog.searchInternalViews(query)` → 结果合并为一个数组
- **AI 模式**：输入自然语言问句 → 复用 AI store 逻辑 → 结果区上方显示 AI 回答摘要，下方混排结果
- **结果混排**：市场商品和内部视图在同一个列表中混排，每行用 `🏪市场` / `🏠内部` 小标签标识来源
- **点击行**：市场商品 → `/portal/product/:id`；内部视图 → `window.open(externalUrl)`
- **空查询**：默认展示全部数据

#### 列表行结构

每行：`[类型标签] [来源标签] 名称 + 描述 | 价格/状态 | 操作箭头`

- 类型标签：数据集(蓝)、API(紫)、报告(橙)、看板(青)、🏠内部(绿)
- 市场商品右侧显示价格（¥299/12个月、会员免费、免费）
- 内部视图右侧显示"跳转 →"

## App 端调整

### 1. Mine.vue 增加"我的账单"Tab

现有 Tab 栏（成为VIP / 我的订单 / 我的数据 / 我的报告 / 个人信息）新增第 6 个 Tab"我的账单"：

```
成为VIP | 我的订单 | 我的账单 | 我的数据 | 我的报告 | 个人信息
```

- 点击"我的账单"进入已有的 `ApiUsageBills.vue` 页面
- 6 个 Tab 横向排列

### 2. API 订单详情增加用量区块

当商品类型为 API 时，订单/商品详情页新增"用量明细"区块：

```
┌─────────────────────────────────┐
│  📊 用量明细                     │
│  本月调用：168/1000 次           │
│  剩余额度：832 次                │
│  [查看账单详情 →]                │
└─────────────────────────────────┘
```

- 仅 API 类型商品显示此区块
- "查看账单详情"跳转 `ApiUsageBills.vue`

## 设计决策汇总

| 决策点 | 结论 |
|--------|------|
| 导航融入 | App.vue 顶部新增"PC门户"切换项 |
| 门户布局 | 左侧垂直导航 + 内容区（PortalShell） |
| 实现方案 | 独立 PC 视图层，Store/类型/数据复用 |
| 页面范围 | 7 个页面（首页/搜索/商品详情/购买/我的购买/API账单/需求提报） |
| 搜索设计 | 统一搜索（关键词+AI双模式），结果混排，去掉独立AI找数菜单 |
| 导航项 | 5 项（门户首页/搜索发现/我的购买/API账单/需求提报） |
| 商品详情 | 左右两栏（信息+购买面板sticky） |
| 购买结算 | 左右分栏（订单信息+摘要） |
| API账单位置 | A+C：Mine新增"我的账单"Tab + API订单详情内嵌用量区块 |
| App端调整 | Mine.vue 加Tab + API订单详情加用量区块 |
