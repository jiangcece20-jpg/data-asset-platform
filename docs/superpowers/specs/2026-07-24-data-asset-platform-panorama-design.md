# 数据资产平台能力全景图设计

## 1. 目标

为管理层补充一张独立的“数据资产平台能力全景图”，在一页内完整展示八个一级模块及其二级功能，并明确标出 AI 直接参与的能力。

本图只表达目标能力版图和 AI 分布，不展示“已具备 / 建设中 / 待规划”状态，也不重复展开 AI 找数的场景和内部模块。

## 2. 受众与使用场景

- 主要受众：管理层、产品负责人、项目决策人。
- 主要场景：产品蓝图汇报、立项沟通、建设范围对齐、AI 能力分布说明。
- 阅读目标：先看清平台覆盖哪些能力，再快速识别 AI 横向嵌入了哪些环节。

## 3. 内容口径

### 3.1 一级模块

一级模块固定为：

1. 资产接入
2. 资产管理
3. 资产发现
4. 数据治理
5. 资产使用
6. 资产运营
7. 资产服务化
8. 平台底座

### 3.2 二级功能

二级功能与管理文档
`docs/product/2026-07-23-数据资产平台能力全景与AI找数需求.md`
保持一致，共 64 项：

| 一级模块 | 二级功能 |
| --- | --- |
| 资产接入 | 数据源管理、元数据采集、自动扫描、资产注册、同步记录、采集任务与变更发现、元数据智能补全与采集诊断 `✦ AI` |
| 资产管理 | 资产目录、分类分级、标签管理、负责人管理、生命周期与上下架、版本管理、资产分组与专题、智能分类与标签推荐 `✦ AI` |
| 资产发现 | 全局搜索、目录浏览、资源发现、资产详情、专题与最近浏览、语义检索与智能推荐 `✦ AI`、AI 找数 `✦ AI` |
| 数据治理 | 数据标准、数据质量、数据血缘、影响分析、敏感识别 `✦ AI`、问题整改、标准推荐与口径消歧 `✦ AI`、质量异常解释 `✦ AI` |
| 资产使用 | 权限申请、审批、订阅、收藏、下载、API 调用、使用指引、即席查询、报表与看板预览 |
| 资产运营 | 热度与使用次数、用户评价、健康度、价值评估、运营报表与 ROI、低活跃资产治理、AI 运营摘要与治理建议 `✦ AI` |
| 资产服务化 | 数据产品、指标服务、API 服务、数据市场、上下架管理、服务授权与版本、调用统计、交付与履约 |
| 平台底座 | 组织用户、角色权限、审计日志、消息通知、系统与审批集成、私有化部署、License 与模块授权、开放 API 与 Webhook、多租户与运维监控、AI 模型路由与评测 `✦ AI` |

### 3.3 AI 标记

凡 AI 直接参与理解、召回、推荐、生成、分析、诊断或评测的二级功能，统一使用紫色高亮并标记 `✦ AI`。不把规则自动化、定时任务或普通统计误标为 AI。

全图精确标记以下 9 项 AI 能力：

1. 元数据智能补全与采集诊断
2. 智能分类与标签推荐
3. 语义检索与智能推荐
4. AI 找数
5. 敏感识别
6. 标准推荐与口径消歧
7. 质量异常解释
8. AI 运营摘要与治理建议
9. AI 模型路由与评测

## 4. 图形设计

### 4.1 画布

- 尺寸：1600 × 1000。
- 方向：横向。
- 页数：单页。
- 标题：数据资产平台能力全景。
- 副标题：8 大能力域 · 64 项二级能力 · AI 能力横向嵌入全链路。

### 4.2 布局

采用 2 × 4 能力矩阵：

- 第一行：资产接入、资产管理、资产发现、数据治理。
- 第二行：资产使用、资产运营、资产服务化、平台底座。
- 每个一级模块使用一张独立卡片，卡片内部按行列出全部二级功能。
- 八张卡片保持同宽同高和平等层级，不使用流程箭头，避免暗示不存在的先后顺序。

推荐几何：

- 标题区：`x=40, y=25, w=1520, h=70`
- 第一行卡片：`y=130, h=390`
- 第二行卡片：`y=540, h=390`
- 四列卡片：`x=40 / 430 / 820 / 1210, w=350`
- 页脚说明：`x=40, y=950, w=1520, h=30`

### 4.3 视觉编码

- 一级模块标题：深蓝色标题栏，白色标题文字。
- 普通二级功能：中性深灰文字、浅灰分隔或白色背景。
- AI 二级功能：浅紫色圆角底、紫色描边和文字，标题前保留 `✦ AI`。
- 图例：标题区右侧展示 `✦ AI`，说明“AI 直接参与理解、推荐、生成、分析、诊断或评测”。
- 页脚强调：AI 不是孤立模块，而是横向嵌入资产接入、管理、发现、治理、运营和平台底座。
- 不使用状态颜色，不出现“已具备 / 建设中 / 待规划”。

## 6. 文件约束

- Draw.io 使用单页、未压缩、原生可编辑的 `mxGraphModel`。
- 所有 `mxCell.value` 使用纯文本和 `html=0`，换行使用 `&#xa;`。
- SVG 使用标准 `rect`、`text`、`tspan` 等元素。
- SVG 不使用 `foreignObject`、嵌入 HTML、脚本、外部字体、远程资源或外部图片。
- PNG 由最终 SVG 机械生成，尺寸必须为 1600 × 1000。

## 7. 验收标准

- 八个一级模块名称、顺序和数量准确。
- 64 项二级功能完整，无遗漏、重复或错放。
- 9 项 AI 功能均使用紫色高亮和 `✦ AI`，普通功能不误标。
- 图中不显示任何建设状态。
- Draw.io 与 SVG 的文字内容一致。
- PNG 与最终 SVG 一致。
- 原尺寸检查无文字裁切、越界、贴边或重叠。
- 八张卡片层级平等，管理层能在一页内完成浏览。
- 管理文档中的三种格式链接均可解析到实际文件。
