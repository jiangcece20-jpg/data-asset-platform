# 商品卡片内容总结与详情默认页签设计

## 目标

列表先说明商品内容和用途，不直接暴露数据字段或接口文档。详情页按商品类型选择默认信息层级。

## 适用范围

- APP 与 PC 商品列表。
- APP 与 PC 数据集、API、行业报告、自有看板详情。
- 运营后台商品编辑。
- 数据集、API 的 Mock 商品数据。

## 列表卡片

### 数据集

系统从已有商品信息生成“内容总结”，说明：

- 包含什么数据。
- 主要覆盖范围。
- 时间或空间粒度。
- 更新特征。

卡片不直接展示字段名、字段值或样例数据行。

### API

系统从已有商品信息生成“内容总结”，说明：

- 解决什么业务问题。
- 需要哪类业务信息。
- 返回哪类判断或结果。
- 主要服务特征。

卡片不直接展示接口路径、请求参数、返回字段或响应样例。

### 报告与看板

保持现有内容优先展示：

- 报告展示封面、摘要或公开正文。
- 看板展示公开指标与趋势。

## 内容来源

| 商品来源 | 内容总结来源 | 规则 |
| --- | --- | --- |
| APP 内容 | 商品详细描述、覆盖范围、更新频率和类型信息 | 按固定规则摘取 |
| 资产平台 | 商品详细描述、资产覆盖、粒度、更新频率和规模 | 按固定规则摘取 |
| 可信空间 | 同步的商品描述、覆盖范围、服务特征和类型信息 | APP 只读摘取 |

生成规则：

1. 主句取商品详细描述首个完整句子。
2. 数据集补充覆盖范围、时间或空间粒度、更新频率、数据规模中已配置且不重复的内容。
3. API 补充适用场景、主要返回结果和 SLA 中已配置且不重复的内容；参数只取中文业务含义。
4. 卡片最多展示三行，超出截断，不重复推荐语。
5. 详细描述为空时回退商品副标题。
6. 仍为空时展示“内容说明准备中”，不得回退字段名、字段值、接口路径、参数名或响应样例。

本期使用固定规则摘取，不调用 AI 生成，保证结果稳定并可测试。

## 详情默认页签

| 商品类型 | 默认页签 | 后续页签 |
| --- | --- | --- |
| 数据集 | 基本信息 | 样例数据、字段信息、探查报告 |
| API | 基本信息 | 接口文档、在线调试、错误码与 SLA |
| 行业报告 | 在线阅读 | 目录、报告介绍 |
| 自有看板 | 看板预览 | 指标定义、基本信息、更新与导出 |

APP 与 PC 使用相同顺序。用户切换商品时进入新商品类型的默认页签。

## 后台配置

- 不新增“内容总结”输入项。
- 继续维护详细描述、覆盖范围、更新频率和类型信息。
- 可信空间已有字段只读，标识“可信空间同步”。
- 编辑页增加列表卡片预览，展示规则摘取结果。

## 验收

1. 数据集列表卡片不出现字段名和样例值。
2. API 列表卡片不出现接口路径、请求参数和返回字段。
3. 数据集与 API 卡片从已有配置生成可读内容总结。
4. 详细描述为空时回退副标题；两者都为空时展示准备中文案。
5. 数据集和 API 详情默认进入基本信息。
6. 报告默认进入在线阅读；看板默认进入看板预览。
7. APP 与 PC 行为一致。
8. 后台无需新增摘要字段；编辑页能预览生成结果；可信空间配置保持只读。
