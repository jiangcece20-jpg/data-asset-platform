# 商品卡片内容总结与详情默认页签设计

## 目标

列表先说明商品内容和用途，不直接暴露数据字段或接口文档。详情页按商品类型选择默认信息层级。

## 适用范围

- APP 与 PC 商品列表。
- APP 与 PC 数据集、API、行业报告、自有看板详情。
- 运营后台商品编辑。
- 数据集、API 的 Mock 商品数据。

## 列表卡片

### 数据集

展示独立“内容总结”，说明：

- 包含什么数据。
- 主要覆盖范围。
- 时间或空间粒度。
- 更新特征。

卡片不直接展示字段名、字段值或样例数据行。

### API

展示独立“内容总结”，说明：

- 解决什么业务问题。
- 需要哪类业务信息。
- 返回哪类判断或结果。
- 主要服务特征。

卡片不直接展示接口路径、请求参数、返回字段或响应样例。

### 报告与看板

保持现有内容优先展示：

- 报告展示封面、摘要或公开正文。
- 看板展示公开指标与趋势。

## 内容来源

| 商品来源 | 内容总结来源 | 编辑规则 |
| --- | --- | --- |
| APP 内容 | 运营后台“内容总结” | 可编辑 |
| 资产平台 | 商品包装时维护“内容总结” | 可编辑 |
| 可信空间 | 同步可信空间商品描述 | APP 只读 |

内容总结为空时回退商品详细描述。详细描述也为空时展示“内容说明准备中”，不回退字段或接口文档。

## 详情默认页签

| 商品类型 | 默认页签 | 后续页签 |
| --- | --- | --- |
| 数据集 | 基本信息 | 样例数据、字段信息、探查报告 |
| API | 基本信息 | 接口文档、在线调试、错误码与 SLA |
| 行业报告 | 在线阅读 | 目录、报告介绍 |
| 自有看板 | 看板预览 | 指标定义、基本信息、更新与导出 |

APP 与 PC 使用相同顺序。用户切换商品时进入新商品类型的默认页签。

## 后台配置

- 标题与展示区域增加“内容总结”多行输入。
- 仅数据集和 API 必填；报告、看板继续使用类型内容预览。
- 可信空间商品字段只读，标识“可信空间同步”。
- 编辑预览同步展示列表卡片效果。

## 验收

1. 数据集列表卡片不出现字段名和样例值。
2. API 列表卡片不出现接口路径、请求参数和返回字段。
3. 数据集与 API 卡片展示可读内容总结。
4. 内容总结为空时展示详细描述；两者都为空时展示准备中文案。
5. 数据集和 API 详情默认进入基本信息。
6. 报告默认进入在线阅读；看板默认进入看板预览。
7. APP 与 PC 行为一致。
8. 后台能维护 APP 内容和资产平台商品总结；可信空间总结只读。
