# 找数买数 · 空间商品改为意向单，并补齐空间/样例/试用标签

- 日期：2026-08-24
- 分支：`feature/find-buy-product-plan`
- 范围：对外 APP / PC 门户的空间数据集与空间 API 发现、评估、购买入口；运营后台意向单跟进与空间处理入口；商品固定标签。协同对象含万联易达可信空间及其他互联空间。
- 状态：原型已按计划落地

## 背景

现行方案里，空间数据集和空间 API 在本平台展示后，认证企业会跳转可信空间自行成交。成交、合同、付款、交付都以空间为准，本平台不保证数据回到自己这边。

现在供给不只来自自有空间，还和其他空间互联互通。用户需要先判断数据来自哪个空间、数据集有没有样例、API 有没有试用接口。正式使用不再让用户自己跳去下单，而是提交意向单，由运营线下到空间代办；数据集成交后必须接到本平台。

## 目标

1. 用户在本平台能发现空间商品，并靠固定标签判断来源空间、数据集样例、API 试用接口。
2. 用户不再跳转空间购买。主操作是提交意向单。
3. 成交、合同、付款仍在对方空间完成，买方是用户企业；运营只代为沟通和下单。
4. 空间数据集成交后必须交付到本平台用数 / 「我的数据」。
5. 自有空间对外名称统一为「万联易达可信空间」，不写成「万联可信空间」。

## 非目标

- 用户侧跳转空间下单、支付。
- 本平台真实调用空间 API，或提供调试台 / 临时密钥。
- 数据集再拆「有无试用接口」。
- 把空间 API 接到本平台代调用。
- 个人作为空间买方在空间成交。
- 意向单和「搜不到货的需求提报」合成一张单。
- APP / 门户对用户展示「自有 / 互联」。
- 改变 APP 自营报告/看板、资产平台数据集的现有购买路径。

## 一句话定位

本平台负责找数、看样例、收意向、盯数据集交付；对方空间负责成交；运营是两者之间的经办人。

## 主链路

1. 用户在本平台找到空间数据集或空间 API，看到来自哪个空间。
2. 数据集有样例则可看脱敏样例；API 可看样例入参 / 出参。未登录也能看这些样例。
3. 要正式使用就提交意向单。登录用户（含个人）可提交。
4. 运营领取意向单，确认落到哪家认证企业，再去对方空间代为沟通和下单。
5. 合同和付款在空间完成，买方是该认证企业。
6. 数据集：空间成交后接入本平台用数，用户在「我的数据」使用。
7. API：空间成交后仍在对方空间使用；本平台只记录成交结果和使用说明。
8. 用户侧意向单只显示：已提交、处理中、已完成 / 已关闭。

用户路径上不再出现「前往空间购买」。运营后台可以保留「去空间处理」，这是经办工具，不是用户购买按钮。

## 命名

| 对象 | 对外名称 | 说明 |
| --- | --- | --- |
| 本平台自有可信空间 | 万联易达可信空间 | 不得简称或误写为「万联可信空间」 |
| 其他互联空间 | 各空间正式名称 | 与自有空间并列展示空间名称 |
| 用数侧已有产品名 | 保持现有名称（如万联灵析） | 本次不改用数产品品牌 |

「万联」与「万联易达」是两家公司。凡用户或运营能看到的空间名称，自有空间一律用「万联易达可信空间」。

## 标签

空间商品使用固定标签，不靠自由文本硬写这三类信息。

### 来自哪个空间

商品资料同时有：

- 空间名称
- 来源类型：自有 / 互联

用户侧（APP / 门户）只展示空间名称，例如「万联易达可信空间」「某某空间」。

「自有 / 互联」只在运营后台展示，也可按这个筛选。用户侧不强调这个分类。

### 数据集：有无样例数据

- 仅数据集使用。
- 取值：有样例 / 无样例。
- 有样例：列表、详情可展示「有样例」，详情可打开脱敏样例。
- 无样例：不出现预览入口，不假装能看样例。
- 数据集不再区分「有无试用接口」。

### API：有无试用接口

- 仅 API 使用。
- 取值：有试用接口 / 无试用接口。
- 这是筛选和识别标签，不增加本平台真实调用能力。
- 有 / 无试用接口时，详情都先展示样例入参、样例出参；差别只是标签是否出现、能否按此筛选。

### 筛选

| 角色 | 可筛条件 |
| --- | --- |
| 用户 | 空间名称、数据集有无样例、API 有无试用接口 |
| 运营 | 上述全部，外加自有 / 互联 |

### 维护来源

- 空间名称、自有 / 互联：随空间目录同步，运营不手工改来源归属。
- 数据集有无样例、API 有无试用接口：以空间同步为准；未同步到则标「无」，前台不得空口宣称「有」。

## 样例与评估

### 数据集样例

- 有「有样例」时，详情提供「查看样例」。
- 未登录可看。
- 内容是脱敏样例（少量行、结构示意），不是全量数据，也不能当正式数据下载。
- 看样例不产生意向单，也不跳转空间。

### API 样例出入参

- 详情先展示样例入参、样例出参。
- 未登录可看。
- 本平台不提供在线真实调用、调试台或临时密钥。
- 「有试用接口」不改变上述限制。
- 真实调用只能提交意向单，由运营线下处理。

### 主按钮

空间数据集、空间 API 的主操作是「提交意向单」。不出现「前往空间购买」或「立即调用」。看样例、看出入参不是下单。

## 意向单

意向单绑定具体空间商品，表示用户想买这一件。搜不到货时的需求提报仍分开，不和意向单混单。

### 谁能提交

- 未登录：先登录。
- 登录用户都能提交，个人也可以。
- 运营跟进后必须落到一家认证企业，才能去对方空间成交。
- 个人不能作为空间买方。

### 用户填写

尽量少填：

- 商品（自动带入）
- 联系人、联系方式
- 使用场景或需求说明
- 已认证企业用户可选择本企业；个人或尚未认证的，可注明希望落到哪家企业，或留给运营确认

### 用户可见状态

| 用户状态 | 含义 |
| --- | --- |
| 已提交 | 意向单已生成，运营尚未形成明确后续结果 |
| 处理中 | 运营已跟进：确认企业、空间成交或数据集接入均属这一档 |
| 已完成 | 数据集已接入本平台可使用；或 API 已在空间成交且本平台已记录结果和说明 |
| 已关闭 | 谈不成、用户放弃、无法落到认证企业，或其他原因终止 |

用户不拆看「待确认企业 / 空间成交中 / 待接入交付」。

用户状态与运营状态对应：

| 运营状态 | 用户状态 |
| --- | --- |
| 待领取 | 已提交 |
| 待确认企业、空间成交中、待接入交付 | 处理中 |
| 已完成 | 已完成 |
| 关闭 | 已关闭 |

提交时已选择认证企业的，运营领取后可直接进入空间成交中，不必再经待确认企业。未选择或个人提交的，必须先待确认企业。

数据集在接入本平台完成前，用户侧保持处理中，不显示已买到。

## 运营跟进

### 运营后台状态

| 运营状态 | 含义 |
| --- | --- |
| 待领取 | 新单，尚未有负责人 |
| 待确认企业 | 需要把意向落到一家认证企业 |
| 空间成交中 | 企业已确认，运营正在对方空间沟通或下单 |
| 待接入交付 | 仅数据集：空间已成交，尚未接到本平台用数 |
| 已完成 | 数据集已接入并可使用；或 API 空间成交结果已回填 |
| 关闭 | 终止，必须填写原因 |

未确认认证企业之前，不能进入空间成交中。

### 运营动作

1. 领取意向单，联系用户，确认落到哪家认证企业。
2. 用后台「去空间处理」进入对方空间，代为沟通、下单。合同和付款仍在空间完成，买方是用户企业。
3. 回填空间订单号、成交商品和说明。
4. API：回填完成后即可将意向单标为已完成。用户仍在空间使用 API，本平台只给结果和说明，不开通本平台调用。
5. 数据集：空间成交后进入待接入交付；接到本平台用数、用户能在「我的数据」看到并使用后，才能标为已完成。
6. 无法继续时关闭，并写原因。

用户自己去空间成交，不算本平台交付成功。正式路径是：意向单 → 运营代办 →（数据集）接入本平台。

## 交付边界

| 商品类型 | 成交位置 | 用户最终使用位置 | 本平台必须做到 |
| --- | --- | --- | --- |
| 空间数据集 | 对方空间 | 本平台用数 / 我的数据 | 成交后接入本平台，接入完成前不显示已买到 |
| 空间 API | 对方空间 | 对方空间 | 记录成交结果和使用说明，不代调用 |

付款、发票、合同主体与空间买方一致，均为该认证企业。本平台不向用户收空间商品的款，也不在本平台生成空间商品的支付订单。

## 对现有规则的替换

| 现行口径 | 本次口径 |
| --- | --- |
| 认证企业跳转空间购买 | 任何登录用户提交意向单；仅认证企业可作为空间买方，由运营代办 |
| APP 镜像或回看空间订单为主路径 | 用户看意向单三档状态；数据集以本平台「我的数据」为准 |
| 可信空间商品主按钮「前往可信空间购买」 | 「提交意向单」 |
| 空间名称可写「万联可信空间」 | 自有空间必须写「万联易达可信空间」 |
| 标签以自由文本为主 | 空间名称、数据集样例、API 试用接口为固定标签 |

资产平台数据集、APP 自营报告 / 看板的购买、支付、交付规则不变。

## 验收要点

- 空间数据集 / API 详情和列表不再引导用户跳转购买。
- 未登录可看数据集样例和 API 样例出入参；提交意向单必须登录。
- 个人可提交意向单；未落到认证企业时，运营不能把它推进到空间成交。
- 用户只能看到已提交 / 处理中 / 已完成 / 已关闭。
- APP 只展示空间名称；运营可按自有 / 互联筛选。
- 数据集可按有无样例筛选；API 可按有无试用接口筛选；数据集没有试用接口标签。
- 数据集意向单在本平台用数可用之前，用户侧不是已完成。
- API 意向单完成后，本平台没有可调用的接口，只有说明。
- 用户可见文案中的自有空间名称是「万联易达可信空间」。
