# 数据集单字段数据探查规则（第一期）

日期：2026-08-29  
范围：找数买数「探查报告」单字段统计口径与计算策略  
状态：已对齐，已回写功能说明 / 完整模块 PRD（2026-08-31）

## 1. 目标

为买前质量信号提供可解释、可落地的字段探查结果。优先保证大表不拖垮交互与集群：轻量占比类允许抽样；分布类第一期一律全量，超时失败重试。

非目标（第一期不做）：

- 独立的「标识型」探查类型与专用 UI
- 唯一值的近似算法（如 `APPROX_COUNT_DISTINCT`）；第一期用抽样 + `COUNT DISTINCT`
- 分布类（直方图 / Top10 / 时间分布）的采样降级

## 2. 字段类型与展示

| 探查类型 | 判定 | 展示指标 |
|----------|------|----------|
| 数值型 | 由字段数据类型映射（integer / decimal / float 等） | min、max、空值率、唯一值率、等宽 10 桶直方图 |
| 字符串（合并） | 字符串类字段；**不区分**标识型 / 分类型 | 空值率、唯一性（唯一值率）、Top10 值分布 |
| 时间型 | date / timestamp 等 | 最早/最晚、跨度、空值率、唯一值率、时间分布 |
| 布尔型 | boolean | TRUE/FALSE 计数与占比、空值率、唯一值率 |
| 标识型 | — | **第一期不做** |

运营配置：后台勾选字段是否开放探查（沿用现有 `profilingEnabled`）。字符串字段**不再**让运营选择「标识 / 分类」。

## 3. 公共计算规则

### 3.1 空值率、唯一值率（可抽样）

- 允许抽样；样本行数上限默认 **100 万**。
- 表行数 ≤ 100 万：等价全量。
- 表行数 > 100 万：抽取不超过 100 万行后计算。
- 唯一值率：在样本上 `COUNT DISTINCT` / 非空样本行（或约定分母口径与产品文案一致），**不做**近似去重算法。
- 前台须标明「采样近似」（或等价文案），避免被当成精确全表统计。

### 3.2 更新时间

展示口径优先级：

1. SelectDB `information_schema.tables.UPDATE_TIME`（文档定义为表数据更新时间，**可查询**）
2. 若为空/不可用：相关分区 `VisibleVersionTime` 的最大值
3. 再不行：本次探查任务完成时间

上线前须在真实同步表上验证 `UPDATE_TIME` 是否有稳定非空值。`SHOW TABLE STATS.updated_time` 不作主口径（易与统计信息收集时间混淆）。

### 3.3 分布类（第一期一律全量）

以下指标**不抽样**，超时则任务失败并重试：

- 数值直方图
- 字符串 Top10
- 时间年 / 年季 / 年月分布

空值率 / 唯一值率与分布类**分开计算**：前者可抽样，后者全量。

## 4. 分类型细则

### 4.1 数值型 — 直方图

算法：

1. 全量取该字段 `MIN`、`MAX`（空值不参与）
2. 若 `MIN = MAX`：单桶即可
3. 否则将 `[MIN, MAX]` 等宽切成 **10** 个桶
4. 统计每桶行数与占比

桶边界约定：左闭右开，最后一桶右闭（实现时写死一种，前后端一致）。

### 4.2 字符串 — 唯一性 + Top10

- 唯一性：走 §3.1 抽样规则
- 值分布：固定 **Top 10**（按出现次数降序），全量计算
- 不单独提供「标识型」唯一性样例格式等专用模块

### 4.3 时间型 — 多粒度分布

- 同时支持并展示切换：**年 / 年季 / 年月**
- **默认粒度：年月**
- 三种粒度结果均可预计算后缓存，或按切换查询；产品上必须三种都可看
- 分布全量计算

### 4.4 布尔型

- TRUE / FALSE 计数与 TRUE 占比
- 空值率、唯一值率走 §3.1

## 5. 与现有原型的关系

现有领域类型见 `external-app-vue3/src/types/domain.ts`：

- 今日仍含 `identifier` / `categorical` 分立模型
- 第一期产品口径改为字符串合并；实现时需收敛类型（例如统一 `string`/`categorical` 形状同时带 `uniqueness` + `topValues`），并调整门户/移动端探查面板文案与 mock

后台「数据探查配置」：继续字段勾选开放；去掉（或不再引入）标识/分类人工分流。

## 6. 验收要点

- 大表空值率 / 唯一值率不超过约 100 万行样本，且 UI 有采样提示
- 数值直方图恒为 10 桶等宽（或 min=max 单桶）
- 字符串同时有唯一值率与 Top10
- 时间分布默认年月，可切年、年季
- 无独立标识型维度
- 更新时间优先来自 SelectDB 表元数据，并有明确降级链
- 直方图 / Top10 / 时间分布全量失败时可重试，不静默改采样

## 7. 决策记录

| 议题 | 决定 |
|------|------|
| 唯一值率算法 | 抽样后 COUNT DISTINCT（非 APPROX） |
| 抽样范围 | 仅空值率、唯一值率；分布类另算且全量 |
| 分布类过大表 | 一律全量，超时失败重试 |
| 标识 vs 分类 | 第一期不区分；字符串合并，同时算唯一性与 Top10 |
| 时间默认粒度 | 年月 |
| SelectDB 更新时间 | 优先 `UPDATE_TIME`，需环境确认 |
