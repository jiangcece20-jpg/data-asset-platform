# 找数买数 · 商品包装改为直接编辑与清晰上下架

- 日期：2026-08-20
- 分支：`feature/find-buy-product-packaging`
- 范围：`external-app-vue3` 运营后台资源列表 / 资源编辑页，以及 catalog 销售状态对前台可见性的影响
- 状态：已落地（原型）

## 背景

运营把资源变成可售商品，现在要先点「包装为商品」、弹窗填名称/副标题/价格、生成草稿，再进编辑页把同样字段再填一遍。列表上另有一键下架；编辑页还有「提交审核 → 审核通过并发布」。包装、上架、审核、下架叠在一起，入口多余，销售状态也不好看清。

## 目标

1. 去掉包装弹窗。未上架资源与已有商品都从列表「编辑」进入同一编辑页。
2. 保存草稿与上架分开：保存不出现在前台；上架后才可搜可买。
3. 编辑页状态条只露出当前可做的销售动作：上架、停新购、恢复销售、下架、重新上架。
4. 销售状态对运营和前台用同一套词：未上架、草稿、已上架、暂停新购、已下架。

## 非目标

- 不做商品审核流（提交审核、待审、驳回、审核通过并发布）。原型包装路径不再出现这些按钮。
- 不接下架/停新购到逆向工单，不做影响清单、客户通知、退款、召回。
- 不改入驻商家上架审、强制下架、卖家暂停连动。
- 不改可信空间价格权威；空间方案在编辑页仍只读。
- 不改一期「一个商品绑定一个资源」、不引入商品包。
- 不改内部 React 数据资产平台。

## 销售状态

界面只展示下面五种，由「有没有商品」和 `product.availability` 推导，不再把 `product.status`（draft / pending_approval / published）单独展示给运营。

| 界面状态 | 条件 | 搜索/推荐 | 商品详情 | 新购 |
| --- | --- | --- | --- | --- |
| 未上架 | 该资源没有商品 | 不出现 | 无 | 无 |
| 草稿 | 有商品，且 `availability` 为 `preparing` 或 `candidate` | 不出现 | 无前台详情 | 无 |
| 已上架 | `availability === 'published'` | 出现 | 可进 | 可买 |
| 暂停新购 | `availability === 'paused'` | 默认不出 | 已购/历史订单可进 | 禁用，文案为暂停新购 |
| 已下架 | `availability === 'delisted'` | 不出 | 历史订单/权益可进 | 不可买 |

写入时同步 `status`，避免种子数据和旧逻辑分叉：

| 动作 | `availability` | `status` |
| --- | --- | --- |
| 第一次保存草稿 | `preparing` | `draft` |
| 上架 / 重新上架 | `published` | `published`，并更新 `listedAt` |
| 停新购 | `paused` | 保持 `published`（表示曾经上架） |
| 恢复销售 | `published` | `published` |
| 下架 | `delisted` | `delisted` |

现有 `pending_approval` / `rejected` / `pending_publish` 类型保留，本页不再写入。若种子数据仍带这些 `status`，界面按 `availability` 归入上表；`availability` 不是 published/paused/delisted 时一律显示为草稿。

`discoverable` 只返回 `availability === 'published'` 的商品（可继续要求 `status === 'published'` 与写入规则一致）。暂停新购、已下架、草稿都不进默认搜索和推荐。

## 资源列表

路径：`/#/admin/resources`。

- 操作列只保留「编辑」。删除「包装为商品」和列表一键「下架」。
- 销售状态列按上一节五种展示（未上架 / 草稿 / 已上架 / 暂停新购 / 已下架），不再展示「准备中、已暂停」等旧标签混用。
- 点「编辑」一律进入 `/admin/resources/:resourceId`，无论有没有商品。
- 用数视图仍可进编辑，只读，不能上架。
- 资产平台「可商品化 / 不可商品化」仍在列表展示。资格不够时编辑页没有上架按钮，状态条写明原因。

## 编辑页

未上架资源打开编辑页时即可填写商品信息（名称默认资源名）。不再要求先创建商品再出表单。第一次保存才创建商品记录。

### 状态条

页顶固定状态条：左为当前销售状态，右为当前可点按钮。表单底部现有「保存」与状态条保存是同一动作。

| 当前状态 | 按钮 | 结果 |
| --- | --- | --- |
| 未上架 | 保存草稿、上架 | 保存 → 草稿，前台不可见；上架 = 先保存再发布 |
| 草稿 | 保存、上架 | 保存仍为草稿；上架后进前台 |
| 已上架 | 保存、停新购、下架 | 保存不改销售状态；停新购拦新买、已购照常用；下架离开搜索/推荐 |
| 暂停新购 | 保存、恢复销售、下架 | 恢复后回到已上架 |
| 已下架 | 保存、重新上架 | 重新上架回到已上架 |

用数视图、或资产平台 `commercializable === false` / `assetStatus !== 'published'`：状态条只说明原因，无上架、停新购、下架、重新上架。

### 确认

- 保存草稿：不弹确认。
- 上架、重新上架、停新购、恢复销售、下架：各一句二次确认后执行。
- 停新购、恢复、下架：不重跑上架校验，只改销售状态。

### 上架校验

保存草稿：

- 必填：商品名称。
- 价格、说明书、类型配置未填完可以存，页面可提示未完成，不打断。
- 格式错误才拦住：会员折扣须在 1–9.9；可售卖周期须为正整数。

上架 / 重新上架（先保存当前表单，通过后才改状态；失败停在本页并标字段）：

| 检查 | 失败落点 |
| --- | --- |
| 商品名称非空 | 名称 |
| APP 付费商品：勾选免费，或至少启用个人单品、企业单品、某一级会员权益之一 | 价格方案 |
| 免费与付费配置互斥（勾选免费则忽略付费输入） | 价格方案 |
| 付费商品须有可售卖周期（≥1 个月） | 周期 |
| 已启用单品须有价格；会员折扣须有折数 | 对应行 |
| 看板：每条指标须有名称和定义 | 看板指标区 |
| 用数视图或不可商品化 | 无上架按钮 |
| 可信空间商品 | 本页不改价；有可展示的同步价格即可上架 |

非必填：副标题、推荐语、说明书、数据集粒度/行数/字段数等。空则前台不展示对应项。

已上架后再保存：不把商品打回草稿。价格/周期变更只影响新订单，不改写历史订单。

## 数据与动作

改 `external-app-vue3` 的 catalog 与资源页，不新增后台一级菜单。

- `listResource`：第一次保存草稿时调用（或等价 `createDraftFromResource`）。入参以编辑页表单为准，不再经过包装弹窗。默认名称=资源名。
- 新增或收口销售动作：`publishProduct`（上架/重新上架）、`pauseProduct`（停新购）、`resumeProduct`（恢复销售）、`delistProduct`（下架，已有则沿用，仅改销售状态，不创建逆向工单）。
- 编辑页去掉 `submitProductReview` / `approveAndPublishProduct` 按钮。store 方法可暂留供测试以外调用，本页不再走。
- 未上架时 `editable` 为真（用数视图除外）：展示与已有商品相同的商品信息、价格方案分组；保存时若无商品则先创建再写入字段。
- 空间商品（`dealChannel === 'space_purchase'`）价格区仍只读；销售动作与 APP 商品相同，上架不校验 APP 单品价。

前台沿用现有 `productAccess` / 购买拦截：`paused` 显示暂停新购且不可下单；`delisted` 不可新购；已购从「我的」或订单进入详情不受搜索过滤影响。

## 测试

至少覆盖：

- 资源列表不再出现「包装为商品」和下架按钮，未上架行只有编辑。
- 未上架资源进入编辑页可填表单；保存后出现草稿商品，`discoverable` 不含它。
- 缺名称不能上架；付费商品未配任何可售方式不能上架；免费商品可上架。
- 上架后进入 `discoverable`；停新购后新购被拦、已购权益仍在；下架后不在搜索、历史订单仍可追溯；重新上架回到可搜可买。
- 用数视图与不可商品化资源不能上架。
- 更新 `catalog.test.ts`、`ResourceCenter` / `ResourceEdit` 相关测试，删掉或改写「包装弹窗 / 提交审核 / 审核发布」的 UI 断言。

## 实现边界

只改 `external-app-vue3` 内资源中心、资源编辑、catalog store 及其测试。功能说明 PRD 中「创建商品进入草稿编辑」「暂停新购 / 下架」与本设计一致的部分，实现后按仓库文档同步规则回写；审核职责分离改为原型包装路径不再演示。逆向工单页面保持原样，不在本次接线。
