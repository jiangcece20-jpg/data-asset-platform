# 通用产品线切换器（product-switcher）使用说明

- 日期：2026-07-14
- 形态：框架无关 Web Component + 远程配置 JSON
- 源码：`public/widgets/product-switcher.js`（随主平台部署）
- 配置：`public/widgets/product-lines.json`（**唯一的产品线清单来源**）

## 设计原则

组件代码和产品线数据分离。**新增平台、改名、换链接、改状态，只改 `product-lines.json`**，主平台重新部署后（或直接在 Pages 上热替换该文件），所有接入站点即时生效——各站点不需要改代码、不需要发版。

## 各端接入方式

### 任何站点（HTML / Vue / 任意框架），两行接入

```html
<script src="https://data-asset-platform.pages.dev/widgets/product-switcher.js" defer></script>

<product-switcher current="chatbi"></product-switcher>
```

- `current`：当前站点的产品线 key（下拉中高亮，点击不跳转）
- `config-url`：可选，默认取脚本同源的 `/widgets/product-lines.json`
- `fallback-icon` / `fallback-name`：可选，配置加载完成前的兜底展示

### React 主平台（已接入）

`AppShell` 使用包装组件 `src/components/product-switcher/ProductSwitcher.tsx`，内部自动注入 script 并渲染自定义元素，兜底展示来自本地 `routes.ts`。

## 配置格式（product-lines.json）

```json
{
  "products": [
    { "key": "data-asset", "name": "数据资产", "icon": "🗃️", "status": "正式",
      "url": "https://data-asset-platform.pages.dev/#search", "hash": "#search" },
    { "key": "chatbi", "name": "智能问数", "icon": "🧠", "status": "正式",
      "url": "https://data-asset-platform.pages.dev/#ai-find", "hash": "#ai-find" }
  ]
}
```

- `url`：绝对地址，跨站跳转用
- `hash`：可选。同一 SPA 内的产品线（如数据资产/数据之源）填 hash；组件在同源或本地开发时走 hash 路由，不整页刷新

## 行为约定

- 点击当前产品线：只收起下拉，不跳转
- 配置拉取失败：降级为只显示当前产品名（无下拉），不打断宿主页面；派发 `product-switcher:error` 事件
- 事件：`product-switcher:ready` / `product-switcher:navigate` / `product-switcher:error`，宿主可监听埋点
- 样式：Shadow DOM 隔离，深色 header 配色，不受宿主样式污染，也不污染宿主

## 注意

- `pages.dev` 的 Pages 部署默认带 `Access-Control-Allow-Origin` 限制吗？——Cloudflare Pages 静态资源默认允许跨域 GET；若未来迁移到自有网关，需为 `/widgets/*` 开 CORS
- 新站点上线流程：① 部署新站 → ② 在 `product-lines.json` 加一条 → ③ 主平台部署/热替换配置，所有站点的下拉即出现新入口
