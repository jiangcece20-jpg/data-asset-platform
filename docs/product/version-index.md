## 使用规则

- 修改版本需求时，必须同步本表和对应模块完整 PRD。
- 模块完整 PRD 中的新增、调整、下线能力需标记 `新增于 <version>`、`调整于 <version>` 或 `下线于 <version>`。
- 本索引只记录产品追溯信息，不记录接口、字段、函数、组件或研发任务拆分。
