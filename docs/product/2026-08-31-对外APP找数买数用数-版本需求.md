## 本版要解决的问题

1. AI 问答仍像「另开一页的搜索落地」，与找数首页割裂；用户期望在找数页内直接问答。
2. 问到平台内商品时，长段摘要 / 指标块抢戏，一期更需要直接看到可点的商品卡。
3. 找数页「数据来源样例」缺资产平台数据集，评审看不到本平台数据集详情形态。
4. 探查报告仍按「分类 / 标识」分叉，与一期可落地统计口径不一致；时间分布缺默认粒度约定。

## 本版用户可感知变更

### 1. 找数页内嵌 AI 问答 · 调整于 2026-08-31

**现行规则：**

| 模式 | 用户看到什么 |
| --- | --- |
| 关键词 | 搜索框、数据来源样例、商品频道；提交后进关键词商品列表 |
| AI 问答 | **仍在找数页内**切换到问答面板：多轮对话、追问、商品卡；不离开找数一级入口 |

- APP 找数页以 Tab（或等价切换）在「关键词 / AI 问答」间切换；两模式各自保留输入与结果上下文。
- 独立「AI 问答」路由可作兼容入口，**主路径**为找数页内嵌问答。
- 关键词路径仍只出商品列表，不混入问答正文。

**下线（下线于 2026-08-31）：**

- ~~找数首页 AI 入口必须以跳转独立 AI 问答页为主路径~~（独立页可保留兼容，不再作为默认体验）

### 2. 平台内命中只出商品卡 · 调整于 2026-08-31

**现行规则：**

- 来源徽章仍为短标签：**平台内** / **含外网**。
- **平台内**且能推荐到商品时：回复主体为 **商品卡**（可带「平台内」徽章）；**不做**长段业务总结、指标块、解锁提示墙。
- 无匹配商品时：短提示（如换问法 / 提交需求），不编造结论。
- **含外网**路径：可保留简短说明 + 外网补充区；与平台商品卡区分展示。

**下线（下线于 2026-08-31，一期）：**

- ~~平台内命中时的 teaser / 多段事实摘要 / 指标卡片作为主呈现~~
- ~~「为你找到 N 个相关商品」等引导性总结文案~~（有卡直接出卡）

### 3. 数据来源样例补资产平台数据集 · 调整于 2026-08-31

**现行规则：**

找数页「数据来源样例」固定清单须覆盖：

1. 自营看板  
2. 空间 API  
3. 行业报告  
4. 个人数据集  
5. 空间数据集  
6. **资产平台数据集**（新增于 2026-08-31）

用于演示不同来源详情页；须含空间 API、空间数据集与资产平台数据集。

### 4. 字段探查第一期口径 · 调整于 2026-08-31

**现行规则（购买前「探查报告」）：**

| 探查类型 | 展示 |
| --- | --- |
| 数值型 | 最小、最大、空值率、唯一值率、等宽 10 桶直方图 |
| 字符串 | 空值率、唯一值率、Top10；**不区分**标识 / 分类 |
| 时间型 | 最早/最晚、跨度、空值率、唯一值率；时间分布支持 **按年 / 按年季 / 按年月**，**默认按年月**；横滑柱状图展示条数与占比；标签 `2026` / `2026Q1` / `2026年01月` |
| 布尔型 | TRUE/FALSE 占比、空值率、唯一值率 |
| 标识型 | **第一期不做**独立类型 |

计算与文案：

- 空值率、唯一值率：允许抽样，样本上限默认 **100 万**；前台标明「采样近似」（或等价）。
- 直方图、Top10、时间分布：**全量**计算；超时失败可重试，不静默改采样。
- 更新时间：优先表数据更新时间 → 分区可见版本时间 → 本次探查完成时间。
- 后台：继续勾选字段是否开放探查；**不再**让运营为字符串选「标识 / 分类」。
- 空间数据集仍不配置探查（承接既有规则）。

## 验收清单（本版）

- [ ] APP 找数页可在关键词 / AI 问答间切换；AI 模式不离开找数一级入口即可多轮追问。
- [ ] 平台内有商品命中时，主呈现为商品卡（可有「平台内」徽章），无长段总结与指标墙。
- [ ] 含外网路径仍可区分展示外网补充；无匹配时短提示，不编造结论。
- [ ] 数据来源样例含资产平台数据集，且仍含空间 API 与空间数据集。
- [ ] 探查报告：字符串同时见唯一性与 Top10；时间默认按年月可切换按年/按年季，横滑柱状图展示条数与占比，标签口径正确；无独立标识型；抽样类有采样提示。
