## 本版要解决的问题

1. 列表标签种类过多，用户分不清系统事实和运营活动。
2. 找数筛选器像芯片墙，选项和列表标签重复。
3. 入驻商家仍按看板/报表上架，找数买不到商家数据集。
4. 卖家上架字段、收款方式和发权时机与平台自营数据集不一致。
5. 「我的订单」卡片一页塞满字段和按钮，扫不过去。

## 本版用户可感知变更

### 1. 列表标签三槽 · 调整于 2026-08-25

**现行规则：** 列表卡片固定三槽。

1. **类型**（必出）：数据集 / API / 行业报告 / 自有看板。
2. **成交位置**：空间商品出空间名（自有空间为「万联易达可信空间」）；入驻商家出卖家名；本平台自营 **空着**，不补「本平台」「APP 支付」之类标签。
3. **运营标签**（最多 1 颗）：优先商品状态（可申请上架 / 准备中 / 暂停销售 / 已下架），否则最多一颗活动标签（如合规首选、热门）。

**下线（保留删除线，下线于 2026-08-25）：**

- ~~列表同时展示成交渠道（APP 支付 / 可信空间购买）~~
- ~~列表展示「有样例」「有试用接口」芯片~~
- ~~列表展示「入驻商家」「空间商品」等来源事实标签（事实改由成交位置槽表达）~~
- ~~列表铺开运营自由标签墙~~

样例、试用接口、渠道仍可在详情页说明，不进列表三槽。

### 2. 找数筛选 · 调整于 2026-08-25

**现行规则：** 结果页两个下拉。

- 全部类型（数据集 / API / 行业报告 / 自有看板）
- 全部位置（本平台 / 各空间名 / 各卖家名 / 入驻商家）

**下线（保留删除线，下线于 2026-08-25）：**

- ~~按业务场景、更新频率、价格特征组合筛选~~
- ~~按数据集有无样例、API 有无试用接口筛选~~
- ~~运营标签下拉~~
- ~~APP 支付 / 来源芯片墙~~

排序四选项不变。

### 3. 空间详情主按钮 · 调整于 2026-08-25

**现行规则：** 空间数据集 / 空间 API 详情主按钮文案为 **「提交试用申请」**。单证仍是意向单，不另建试用审批流。

表单「当前企业」只读回填：已认证企业填当前企业名称；个人身份填「个人」。用户不能改。

**下线（保留删除线，下线于 2026-08-25）：**

- ~~主按钮文案「提交意向单」~~
- ~~希望落到的企业由用户手填或自选~~

### 4. 入驻商家上架对象改为数据集 · 调整于 2026-08-25

**现行规则：** 卖家上架对象为 **数据集**。找数可搜到已发布的商家数据集。购买走单品购买，不走平台数据集采购 / BI 交付。标签仍是「购买数据集」。支付后见第 6 条待开通。

**下线（保留删除线，下线于 2026-08-25）：**

- ~~本期仅看板上架 / 看板竖切~~
- ~~上架对象为看板 / 业务报表视图 / 用数可上架对象~~
- ~~买家购买后打开看板；卖家确认到账后获权打开看板~~

规划中的报告成品上架仍属后续，不因本版放开。

### 5. 卖家数据集交易规则 · 调整于 2026-08-25

**现行规则：**

- 买家把钱打到 **平台**；平台按合同与卖家结算。页面不选、不展示结算方式。
- 上架须同时支持 **个人价** 与 **企业价**；**不支付会员价**，详情不展示会员权益作为可购方案。
- 上架、详情、运营审核 **不展示数据预览截图**。
- 更新频率为下拉枚举：实时更新 / 每日更新 / 每周更新 / 每月更新 / 每季度更新 / 不定期。后台资源管理中有更新频率的字段用同一套枚举。

**下线（保留删除线，下线于 2026-08-25）：**

- ~~卖家自收款；待卖家确认到账后发权~~
- ~~页面明示平台不代收、不担保资金~~
- ~~本期 MVP = 结算 B（卖家自收款）~~
- ~~卖家数据集支持会员价 / 会员免费覆盖~~
- ~~卖家上架或详情要求数据预览截图~~
- ~~更新频率自由填写~~

### 6. 卖家订单待开通 · 新增于 2026-08-25

- 在线支付成功 → 订单 **待开通**，此时 **不发权**。
- 企业合同采购 → 先待付款；运营确认平台到账 → **待开通**；再点开通才发权。
- 运营在入驻商家订单或订单中心执行「开通」后，才发放数据集权益。

**下线（保留删除线，下线于 2026-08-25）：**

- ~~入驻商家支付成功立即发权~~
- ~~卖家确认到账后发权~~

### 7. 我的订单拆成卡片 + 详情 · 调整于 2026-08-25

**现行规则：**

- **列表卡片**只展示：类型、商品名、状态、金额、下单时间。整卡进入订单详情。仅紧急动作留在卡片：**继续付款**。
- **订单详情页**展示主体、渠道、方案、付款方式、下单/付款/到期、订单号、进度、续订、空间商品号，以及查看商品、继续付款、查看我的数据、续订、前往可信空间、下载数据。
- 移动端与 PC 门户共用详情；空间订单与 APP 订单分开展示，避免订单号撞车。

**下线（保留删除线，下线于 2026-08-25）：**

- ~~买数列表卡片完整展示主体、渠道、方案、付款、进度、续订提示和全部操作按钮~~
- ~~从订单卡片直接「查看我的数据 / 查看商品 / 下载数据 / 续订」作为列表常驻按钮~~

意向单 Tab 仍用较简卡片，不强制进同一套详情。

## 验收要点

- 找数列表每张卡最多三槽；自营成交位置为空；筛选用两个下拉。
- 空间详情主按钮为「提交试用申请」；当前企业只读回填。
- 找数能搜到入驻商家数据集；购买为个人/企业单品价，无会员价；无预览截图；无结算方式选择。
- 卖家数据集付款成功后为待开通，运营开通后才进「我的数据」。
- 我的订单列表可扫过；点进详情才能看到完整字段和非常驻操作。
